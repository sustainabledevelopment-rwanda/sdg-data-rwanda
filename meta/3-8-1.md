other_info: This indicator uses data from a number of different sources. The principal sources are listed under the Sources tab on this page, however, sources for some tracer indicators are missing or incomplete. Some additional information on sources is available for tracer indicators which also correspond to another SDG indicator; please see the pages for indicators [3.7.1](https://sustainabledevelopment-rwanda.github.io/3-7-1/), [3.a.1](https://sustainabledevelopment-rwanda.github.io/3-a-1/), [3.c.1](https://sustainabledevelopment-rwanda.github.io/3-c-1/), and [3.d.1](https://sustainabledevelopment-rwanda.github.io/3-d-1/) for more information on sources used for the corresponding tracer indicators.
comments_limitations: The 14 tracer indicators used to calculate this indicator include different sources with different methodologies, including different survey populations, resulting in some level of imprecision.
